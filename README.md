# Mudkid Studio widgets

Small embeddable widgets for Mudkid Studio Notion templates. Self-contained, no accounts, no API keys.

| Widget | URL | What it does |
|---|---|---|
| Analog clock | `/clock/` | Your local time, brand palette |
| Focus timer | `/widgets/timer.html` | Visual countdown disc (Time-Timer style), 5-45 min presets |
| Pomodoro | `/widgets/pomodoro.html` | 25/5 cycles, paw prints fill as sessions complete |
| I did a thing | `/widgets/did-a-thing.html` | Dopamine button: confetti + a kind word + daily counter |
| Gentle reminder | `/widgets/affirmation.html` | One low-pressure line per day |
| Box breathing | `/widgets/breathe.html` | 4-4-4-4 breathing pacer |
| Date card | `/widgets/date.html` | Big friendly weekday + date |

All pages default to a cream card background. Append `?bg=dark`, `?bg=transparent`, or `?bg=RRGGBB` to override.
